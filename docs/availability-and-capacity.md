# 场地总览与容量说明

2026-10-13 更新。生产入口：https://sports.anserlabs.com/

## 查询与采集

采集和页面刷新分开：Cloudflare 每小时从久事代理采集；浏览器每五分钟检查已经发布的快照。点击刷新不会即时请求久事，也不会改写 D1。页面明确显示采集时间。港科大登录现状保留，数据不可用时显示提示，不将缺失数据当作已经订满。

数据路径：源接口 → 条件 UPSERT 到 D1 → 发布源快照到 SLOTS_CACHE KV → Cloudflare 每个位置的五分钟响应缓存 → 浏览器。

公开场地接口不访问 D1，包括并发冷缓存请求。缓存缺失或损坏返回 503，不回退为数据库扫描。源采集失败保留上次成功数据并显示过期提示。KV 跨位置最终一致，Cache API 本身不跨位置共享；这不是全球强一致库存。余位和价格应以官方小程序确认页为准。

阿里云补采在 08:05–22:05 每小时执行，比主 Cron 晚五分钟。若十分钟内已有健康久事快照，则直接跳过上游查询和 D1 写入；近期主采失败时才补采。内部机器令牌与代理令牌分别保存在本机/服务器私有文件中。

## 每日额度与行数

按 Workers Free 的额度预算：D1 每天读取 5,000,000 行、写入 100,000 行，UTC 00:00（北京时间 08:00）重置，账户数据库合计存储 5 GB。当前 OAuth 没有账单订阅读取权限，本次未确认实际账单套餐。付费方案按月包含额度，不能套用免费方案的每日硬限制。

2026-10-13 16:35 北京时间，账户全部 D1 当日累计读取 108,432 行（约 2.17%），写入 12,533 行（约 12.53%）。这是测量时点的累计值，不能视为全天预测，也不能全部归因于 CourtSync。

4,165 条是当时久事未来九天的库存快照，不是每天新增 4,165 条历史记录。D1 保留滚动窗口、删除过期记录，同一场地/日期/开始时间使用主键更新；数据不变不改写 updated_at。正常容量随场地数和预约窗口变化，不会按运行天数无限累积。

如果把 4,165 行每次都重写，15 次采集至少是 62,475 行写入，索引还可能增加计数，不能保证低于 100,000。当前采用条件更新，只写新增或改变的行，再跳过重复补采，因此应以实际 rows_written 指标判断。大规模场地扩展或库存频繁变化仍需重新预算。

压缩 JSON、缩短字段或批量 SQL 可以减少字节、请求次数和延迟；D1 按扫描/写入的行数计费，压缩一行仍是一行，batch 也不自动减少行数。将每天重写数千行改成少量 JSON 行虽可减少写行数，但会失去按场地查询的索引能力并整段改写。这里选择保留结构化 D1，公开查询使用共享 KV 快照。HTTP 已由 Cloudflare 压缩传输，主页只请求七天数据。

其他免费额度也要考虑：Worker 动态请求约 100,000 次/天；KV 读取 100,000 次/天、写入 1,000 次/天。两个源每小时各发布一次约 30 次 KV 写入/天，异常补采可能额外增加。热位置可复用响应缓存，冷位置和同时到达的冷请求仍可能读取 KV。登录、提醒和管理接口仍使用应用 D1。不能保证任意访问量都免费。

## 页面与验证

移动端详情默认为关闭，点击时段后打开浮动卡片，底部留出至少 32px 加系统安全区的距离；面板内容单独滚动，顶部“返回时段筛选”和底部“返回七天总览”保持可见。返回筛选保留时间、时长和周几，关闭后表格保持完整宽度。桌面端详情可收起。筛选器按三列显示清楚的时长、时间、场地标签。构建 CSS 的兼容目标包含 Safari 14/Chrome 88，避免响应式断点被转换为旧微信 WebView 不支持的媒体查询范围语法；不据此声称所有旧浏览器功能都受支持。

时段查找取代仅展示最早三条的“最近可约”：用户可选择上午/下午/晚上，或自定义最早开始、最晚结束（半小时步长），选择连续 1–6 小时和一个或多个周几。先检查七天内全部空闲时段，再按条件筛选；同一场地的完整连续时长必须落在时间范围内，并使用主筛选器选择的场地。结果显示日期、时段、场地数量及名称，点击查看详细场地；大量结果可在同一面板继续展开。所有查找在本地执行，不增加数据库或源接口访问。

主页保留推广区与原有 X（@Kook91513056）、GitHub（@kongdayan）链接。登录和有场提醒入口暂时隐藏，首页不读取登录会话；已有账户功能和通知流程保留。语言与主题选择保存在本机，切换语言不发起新的场地查询。

下载按钮保存当前渲染的场次视图为 PNG，包含当前时长、时段、场地筛选、场地号显示、所选时段详情、语言与主题，以及项目署名和推广链接。图片在浏览器本地生成，不请求 D1，不上传至服务端；图片模块在第一次下载时才加载。

七天始终并排显示，包括暂无数据的日期。数字表示可用场地数量，点击查看具体场地；0、暂无数据和已经开始是不同状态。连续 1–6 小时筛选要求同一场地完整连续空闲，支持半小时源数据。筛选、场地选择和显示场地号均在本地完成。

同一份真实久事快照的受控浏览器检查：旧完整模式约 8,268 个 DOM 节点，旧 compact 模式约 4,593 个，新首页约 520 个。旧初始 JS 约 392 KB，新页面约 343 KB（未压缩解码大小）。加载毫秒数受测试环境影响，不将单次本地时间作为生产性能承诺。
